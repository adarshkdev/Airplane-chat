✈️ Airplane Chat

Private 1:1 chat between two nearby phones. No account and no internet during the chat.

Not connected

First, either person turns on their phone's Wi-Fi hotspot. The other person joins it. Keep Wi-Fi on; mobile data and internet are not needed.

Create chat

Use this on the phone that starts the connection. Generate a code and share it with your friend.

Join chat

Use this on the other phone. Paste the connection code you received.

Pairing uses two code exchanges: offer code → reply code. A single shared PIN cannot connect two browsers without a signaling server. Keep these codes private; they contain temporary connection details.

Your conversation

Keep this page open while chatting. If either phone closes or suspends Chrome, the connection may drop. Chat history is stored only in this browser on this phone.
